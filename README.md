# Template WhatsApp · Sistema Recensioni

## Sequenza "Trattativa aperta"

Messaggi WhatsApp inviati ai contatti che entrano nello stato **Trattativa aperta**. Ogni file contiene solo il testo del messaggio, pronto da incollare.

| # | Quando | Obiettivo | File |
|---|---|---|---|
| 1 | Giorno 2 | Accendere il desiderio di essere scelti | `01-giorno-2-accendere-il-desiderio.txt` |
| 2 | Giorno 5 | Dare una ragione concreta per partire | `02-giorno-5-dare-una-ragione-concreta.txt` |
| 3 | Giorno 7 | Ultimo giorno / portare alla firma | `03-giorno-7-ultimo-giorno.txt` |

- **Merge tag:** `{{contact.first_name}}`, `{{contact.link_di_pagamento_stripe}}`
- **Offerta citata:** 90 €/mese anziché 189 €/mese. Il messaggio del giorno 5 dice che resta disponibile "ancora per 2 giorni", quello del giorno 7 che è l'ultimo giorno: i tempi di invio devono restare giorno 2, 5 e 7.
- **Tono:** "lei" verso il titolare, "vostro/vostra" riferito all'attività.
